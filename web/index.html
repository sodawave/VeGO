The idea

LLMs talk to hosts (Cursor, Codex, vibe CLIs). Instead of emitting verbose Go as the product source, they emit .vego. VeGo expands it to real Go; go build runs it. Humans audit via expand-to-Go — not by reading glyphs.

  • Not a new runtime or cmd/compile fork
  • Alpha gate = fidelity / round-trip, not BPE %
  • Mid-term = measured token savings (vego tokens)

Go ↔ .vego

Same program. Left is what humans review after expand; right is what the agent emits.

package main

import (
  "fmt"
  "net/http"
)

func main() {
  http.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintln(w, "hello vego")
  })
  _ = http.ListenAndServe(":0", nil)
}

  4. 04 Standard go build / go run
